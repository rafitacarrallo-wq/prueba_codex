# Radar Inmobiliario Madrid

Herramienta de una sola página para analizar si comprar un piso en Madrid es una buena inversión.

Sin backend, sin base de datos y sin APIs externas: los 20 barrios están en un JSON fijo
(`src/data.js`) y todos los cálculos se hacen en el navegador (`src/calc.js`).

```bash
npm install
npm run dev      # desarrollo
npm run build    # producción en dist/
```

Datos de mercado orientativos de 2025.
